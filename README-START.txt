KRAFFT-FAHRNAU.DE – WEBSITE STARTPAKET

INHALT:
index.html = komplette Website
assets/ = Bilder aus dem bereitgestellten Krafft-Booklet

GITHUB UPLOAD:
1. ZIP auf dem Computer entpacken.
2. Im Repository armin-historik/krafft-fahrnau die vorhandene index.html durch die neue ersetzen.
3. Den Ordner assets samt Bildern hochladen (GitHub: Add file > Upload files; Ordner ins Upload-Feld ziehen).
4. Commit changes bestätigen.
5. Nach dem Deployment die Testadresse öffnen:
   https://armin-historik.github.io/krafft-fahrnau/
6. Später die eigene Domain krafft-fahrnau.de unter Settings > Pages eintragen und bei United Domains DNS konfigurieren.

WICHTIG VOR VERKAUFSSTART:
- Preis und Versandkosten DE/AT/CH kalkulieren und Verfügbarkeit gedruckter Exemplare bestätigen.
- E-Mail-Bestellablauf und erforderliche rechtliche Angaben prüfen.
- Die bisherige kostenlose Vollausgabe auf Heyzine bleibt unabhängig von dieser Website erreichbar. Für eine reine Leseprobe dort separat umstellen.
- Abbildungsrechte bei geplanter Weiterverwendung prüfen.

Die Website verwendet keine externen Bibliotheken, kein Tracking und keine Datenbank.
